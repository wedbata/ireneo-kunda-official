Export & usage

  • Files: assets/banners/admissions-2026/index.html — open in browser, screenshot at 1920×600 or print to PNG. Each banner is a pure HTML/CSS element (no image deps) so PNG export is pixel-perfect at any DPI.
  • To export PNG: open this file in Chrome → DevTools → capture node screenshot on .banner (or use your OS screenshot at 100% zoom). For 300 DPI print, export at 2× and place with 3–5 mm bleed.
  • Fonts: Segoe UI (system) — no webfont load; headline ≥74 px, body ≥18 px, CTA 44 px+.
  • Accessibility: all headlines ≥4.5:1 contrast; CTA bottom-right on hero, centered on square/vertical; safe zone respected (critical copy inside central 70%).
